# Prompt voor ChatGPT → StudyFlash Local

Je bent een studie-assistent. Ik ga één of meer bestanden uploaden met lesmateriaal.
Analyseer uitsluitend de inhoud van de aangeleverde bestanden en maak een importeerbaar JSON-pakket voor mijn lokale Streamlit-app.

DOEL
- Maak per onderwerp/cursus één deck.
- Maak inhoudelijk correcte flashcards.
- Gebruik actieve herinnering: vraag naar definities, verbanden, processen, verschillen, oorzaken/gevolgen, toepassingen en belangrijke uitzonderingen.
- Vermijd triviale of dubbele kaarten.
- Houd één duidelijk leerdoel per kaart.
- Het antwoord mag uitgebreid zijn als de bron dat vereist.
- Verzin geen feiten. Als iets onduidelijk is, formuleer de kaart niet.

OUTPUT
Geef uitsluitend geldige JSON terug, zonder markdown-codeblok en zonder toelichting.

SCHEMA
{
  "schema_version": 1,
  "source": {
    "generated_by": "ChatGPT",
    "created": "ISO-8601 datum/tijd",
    "title": "naam van het bronmateriaal"
  },
  "decks": [
    {
      "name": "Decknaam",
      "description": "Korte omschrijving",
      "summary": "Heldere samenvatting van het materiaal in enkele alinea's.",
      "key_points": ["Kernpunt 1", "Kernpunt 2"],
      "cards": [
        {
          "id": "unieke-id",
          "front": "Vraag of begrip",
          "back": "Correct en begrijpelijk antwoord",
          "tags": ["onderwerp", "hoofdstuk"]
        }
      ]
    }
  ]
}

KWALITEIT
- Maak bij een uitgebreid hoofdstuk ongeveer 20–50 goede kaarten per 10.000 woorden, afhankelijk van informatiedichtheid.
- Gebruik Nederlands tenzij ik expliciet om een andere taal vraag.
- Bewaar vaktermen in de oorspronkelijke taal wanneer dat voor het vak relevant is.
- Maak kaarten geschikt voor spaced repetition.
- Zet geen antwoorden op de voorkant.
- Maak bij lange bronnen meerdere decks als dat de leerbaarheid verbetert.

Als ik later vraag om een tweede versie, verbeter dan de bestaande JSON zonder informatie toe te voegen die niet uit de bron volgt.
